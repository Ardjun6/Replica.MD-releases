From download
to your first task.

Use a spare Git repository for your first session. ReplicaMD organizes your work; your chosen agent CLI provides the AI.

Before you install

  • A Windows or Linux x64 computer.
  • Git. Windows requires Git for Windows, including Git Bash.
  • A separately installed and authenticated Claude Code, Codex, or OpenCode CLI, and the account or provider access it needs.
  • An independent backup of important project files.

AI subscriptions, API charges, and provider terms apply separately. Local workspace features do not require Google.

Windows

Download ReplicaMD-2.0.8-x64.exe, verify its checksum, and run the installer. The beta is unsigned, so Windows may show an unknown-publisher warning. Check the release source and checksum before choosing to proceed. Native Windows UI acceptance is pending; report installation and first-session problems.

Linux

Download the x64 AppImage and verify the checksum. Mark the downloaded file executable, then launch it:

chmod +x replicamd-2.0.8-x86_64.AppImage
./replicamd-2.0.8-x86_64.AppImage

Some distributions need FUSE support for AppImages. If launch fails, include your distribution and the terminal error in a support report.

Verify your download

Download SHA256SUMS.txt from the same release. Compare the checksum for your exact filename. On Linux, run sha256sum <filename>; on Windows PowerShell, run Get-FileHash <filename> -Algorithm SHA256. A checksum checks file integrity; it does not replace code signing.

Your first task

  1. Create a local profile. Choose a name and color. Email and Google are optional.
  2. Add a spare Git repository. Select a folder you can safely experiment with.
  3. Check your terminal. Open it and run pwd and git status. Confirm you are in the intended project.
  4. Start your chosen agent. Confirm the CLI works and is authenticated. Ask: “Explain this repository’s README and suggest one small documentation improvement. Wait before editing.”
  5. Review one change. Authorize a small edit, inspect its diff, and run the relevant project check.
  6. Keep context. Add a Knowledge note about the task. Quit and reopen ReplicaMD; confirm the profile, project, tabs, and note are present.

Back up before relying on it

Profile exports preserve portable profile/workspace context and references. They are not a complete backup of repositories, running processes, provider credentials, or every app file. Use Knowledge’s separate backup/export for notes and attachments, and keep a normal backup of your Git repositories. Restore a test copy before relying on either export.

Themes and readability

Open Settings to choose appearance and font options. Select a theme you can comfortably read, then check both the editor and terminal. Theme choices do not change provider access or project permissions.

Local development ports

Start your project’s development server from its terminal, then use the local URL printed by that server. A busy port is usually owned by another process: identify it before stopping it, or choose a different port in your project’s configuration. Do not expose a development server publicly unless you intend to.

Optional integrations

Start with a local profile and a working agent CLI. Other integrations are optional and can have their own prerequisites, accounts, or network access. Google remains limited to approved test users. Review the requested permissions and the privacy information before connecting services.

Setup and teardown scripts

Project Settings includes Scripts for automating the agent lifecycle. Use setup for project preparation and teardown for cleanup. These are shell commands: review them as carefully as commands you would run yourself. On Windows the app uses Git Bash, so keep scripts compatible with Bash. First test a harmless command in a spare project, then add installation or cleanup commands deliberately.

Beta boundaries

Windows native UI acceptance is pending. Installers are unsigned. Optional Google is in Testing, limited to approved test users, and may require reconnection. macOS is not offered in this beta. A download does not imply every platform and integration flow has been verified.
